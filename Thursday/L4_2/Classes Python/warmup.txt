1) Vocabulary
https://www.w3schools.com/python/python_arguments.asp
parameter: 
- a placeholder (variable) you can use in a function
i.e. def ...(name) <-- parameter
...("Dylan") <-- argument

property: 
- what "its" (object) about
- information about an object
access an objects property:
- myCircle = [codesters.circle(x,y,...)] object
- myCircle.y
- object.property

method: 
- function that belongs to a class
- behaviour of objects / find information about an object
access an objects method:
- object.method("Dylan")

class: "blueprint" for creating objects, object constructor
