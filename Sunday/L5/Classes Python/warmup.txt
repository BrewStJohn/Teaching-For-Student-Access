1) Vocabulary
parameter: def ...(parameter)
--> creating a variable inside of the function
that can only be used in the function
argument: value passed into a function call for a parameter

property: variables that belong to a class
access a property of an object: object.property
pen.color

method: function defined inside of a class
access a method of an object: object.method()
pen.write()

object: 1) type of data 2) has properties 3) has methods 
class: a blueprint for objects, object constructor
create an object: 
pen1 = Pen("black", "large")
